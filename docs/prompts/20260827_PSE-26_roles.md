## 1. Resumen de la Tarea
Implementación fullstack en Django y Django REST Framework (DRF) para la gestión centralizada de roles y permisos del sistema (PSE-26). Incluye modelos de base de datos para `Role` y `SystemPermission`, endpoints REST para CRUD completo de roles, asignación y desvinculación granular de permisos, validación de políticas de acceso y sincronización con Keycloak, registro persistente de auditoría (`AuditLog`), interfaz gráfica de administración en HTML/Bootstrap, y pruebas unitarias completas bajo Pyunit (`django.test`).

---

## 2. Criterios de Aceptación Evaluados
1. **CRUD de Roles:** Creación, listado, modificación y desactivación (soft delete) de roles dentro de la plataforma.
2. **Permisos Granulares:** Asignación y desvinculación granular de permisos (`SystemPermission`) a cada rol creado.
3. **Sincronización Keycloak:** Validación y sincronización de la estructura de roles y permisos con las políticas de acceso de Keycloak (`keycloak_synced`).
4. **Validación de Roles (RBAC):** Restricción de endpoints y vistas del sistema según el rol del usuario autenticado (requiriendo rol Administrador o privilegios superiores).
5. **Auditoría de Modificaciones:** Registro persistente de eventos de auditoría (`ROLE_CREATED`, `ROLE_UPDATED`, `ROLE_DEACTIVATED`, `ROLE_PERMISSION_ASSIGNED`, `ROLE_PERMISSION_UNLINKED`) con usuario, IP y timestamp.

**Pruebas unitarias ejecutadas con éxito (100% aprobadas):**
- `test_login_success_retail`: Validación de autenticación SSO para cliente minorista.
- `test_login_success_corporate_with_mfa`: Validación de autenticación con MFA para cliente corporativo.
- `test_login_failed_missing_mfa`: Verificación de rechazo por falta de MFA (403 Forbidden).
- `test_login_failed_invalid_credentials`: Verificación de rechazo por credenciales inválidas (401 Unauthorized).
- `test_role_crud_and_keycloak_sync`: Validación de creación, listado, modificación y desactivación de roles con sincronización Keycloak y auditoría.
- `test_granular_permission_assignment_and_unlinking`: Validación de asignación y desvinculación granular de permisos a roles.
- `test_rbac_access_control_denied`: Validación de control de acceso basado en roles (RBAC), denegando acceso a usuarios no administradores (403 Forbidden).
- `test_roles_admin_ui_template`: Validación de acceso a la vista de interfaz gráfica de administración de roles (`roles_admin.html`).
